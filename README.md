**Trace** is an intuitive, web-based carbon footprint tracking application built for the **iTrax Adaptathon**. It helps individuals quantify, understand, and reduce their daily environmental impact through simple data logging and responsive SVG visualizations.

---

## ✨ Features

- **Daily Choice Logging:** Quickly log everyday emissions across Commute (cars, public transit, two-wheelers, cycling/walking), Food (plant-based vs. meat-forward), and Home Energy usage.
- **Dynamic Data Visualization:** Real-time SVG line charts and daily trends render automatically as entries are added.
- **Data Persistence:** Uses `localStorage` to retain tracking history across page refreshes.
- **Actionable Insights:** Displays customized breakdown stats and high-impact reduction suggestions.
- **Fully Responsive UI:** Built with clean modern typography and accessible styling optimized for desktop and mobile.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup and custom form controls.
- **CSS3:** Custom properties, CSS Grid/Flexbox, and responsive UI layouts.
- **JavaScript (ES6+):** Dynamic calculations, DOM interactions, SVG generation, and LocalStorage management.
